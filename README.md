# standalone_interactive_table
A single page self-contained (static hosted) [interactive table webpage](https://dulani.github.io/standalone_interactive_table) (generated primarily by Devin.ai).

This was created as a test of Devin.ai and designed to be an alternative to [this version](https://rand.shinyapps.io/law_database_downloader/) hosted on ShinyApps.io.  There is still more to do to finish mirroring the Shiny app, but what we've got thus far is a nice demo.
